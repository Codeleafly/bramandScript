# Modular Gradebook Application

A modular, production-standard BramandScript application showcasing:
- Multi-file module imports (`models.bmd`, `stats.bmd`, `formatter.bmd`)
- Custom `struct` models with method declarations (`average()`, `letter_grade()`)
- Array and for-in iteration
- Statistical computation functions
- ANSI color formatting (`color`, `styled`)

## Running the Application

```bash
bramand run examples/modular_gradebook/main.bmd
```
