Standard Library Reference

Exhaustive guide to all modular std/... packages, the Terminal UI & CLI framework (std/tui across 11 submodules), scientific math, linear algebra, cryptography, and an exhaustive dictionary of all 182 VM built-in functions.

Standard Library

Modular Standard Library (std/...)

BramandScript adheres to the Lean VM & Modular Standard Library Principle (Rule 12). Rather than polluting the core bytecode execution engine with high-level domain algorithms, capabilities are structured into clean, modular .bmd packages located in the stdlib/ directory.

Natively Resolved Imports

The bytecode compiler automatically resolves import "std/<module>" as <alias> without requiring relative filesystem paths or environment configuration. Modules are compiled once and exported as immutable namespace hashes.
