Standard Library & Math

Standard Library Reference

Modular std/ packages, 256-bit BigInt, high-precision BigFloat, linear algebra, statistical analysis, cryptography, and full built-in functions index.

Standard Library

Modular Standard Library (std/...)

BramandScript v0.1.1 adopts a modern standard library design where the core Virtual Machine remains minimal and lean, while high-level capabilities are organized into modular .bmd packages under stdlib/. You can import modules cleanly using import "std/<module>" as <alias>.

Clean Import Syntax

Importing standard modules works anywhere out-of-the-box without configuring environment paths: import "std/math" as math or import "std/strings" as str.

1. std/math — Mathematical Constants & Functions

Provides high-precision constants and numerical algorithms:

bmd — std/math 
import "std/math" as math

print("Pi:", math.PI)
print("Clamp 15 between 0 and 10:", math.clamp(15, 0, 10)) // 10
print("GCD of 48 and 18:", math.gcd(48, 18))                // 6
print("LCM of 4 and 6:", math.lcm(4, 6))                    // 12
print("Is 4 even?:", math.is_even(4))                      // true

2. std/strings — String Utilities & Formatting

Text processing, padding, casing, and slug generation:

bmd — std/strings 
import "std/strings" as str

print(str.capitalize("bramand"))          // "Bramand"
print(str.pad_left("42", 5, "0"))          // "00042"
print(str.slugify("Hello Bramand World"))  // "hello-bramand-world"
print(str.reverse("stressed"))             // "desserts"
print(str.starts_with("bmd", "bm"))        // true

3. std/collections — Functional Transformations

Functional primitives like map, filter, reduce, unique, and chunk:

bmd — std/collections 
import "std/collections" as coll

let numbers = [1, 2, 3, 4, 5, 6]
let evens = coll.filter(numbers, fn(x) { return x % 2 == 0 })
let doubled = coll.map(numbers, fn(x) { return x * 2 })
let sum = coll.reduce(numbers, fn(acc, x) { return acc + x }, 0)

print("Evens:", evens)     // [2, 4, 6]
print("Doubled:", doubled) // [2, 4, 6, 8, 10, 12]
print("Sum:", sum)         // 21

4. std/json — Safe JSON Parsing & Stringifying

JSON serialization and deserialization:

bmd — std/json 
import "std/json" as json

let raw = "{\"language\": \"Bramand\", \"version\": \"0.1.1\"}"
let doc = json.parse(raw)
print("Language:", doc["language"])
print("Version:", doc["version"])

let output = json.stringify({"status": 200, "ok": true})
print("Serialized:", output)

5. std/io — Safe Filesystem & Console I/O

Clean file reading, writing, atomic appends, directory discovery, and console presentation utilities.

bmd — std/io 
import "std/io" as io

io.print_header("System Diagnostics")
io.write_text("logs/session.log", "Engine started\n")
io.append_text("logs/session.log", "Initialized stdlib\n")

if io.exists("logs/session.log") {
    let content = io.read_text("logs/session.log")
    io.println("Log contents:\n" + content)
}

let entries = io.list_directory(".")
io.println("Directory entries: " + str(entries))

6. std/testing — Unit Assertion Test Suite

Zero-dependency assertions for custom testing suites, regression pipelines, and test runners.

bmd — std/testing 
import "std/testing" as t

t.assert_true(10 > 5, "10 must be greater than 5")
t.assert_false(5 > 10, "5 cannot be greater than 10")
t.assert_not_null("valid", "value must be defined")
t.assert_null(null, "value must be null")
Scientific Math

Arbitrary-Precision BigInt & BigFloat

BramandScript provides native arbitrary-precision arithmetic powered by Go's standard math/big package. Overloaded operators (+, -, *, /, %, **, unary -) and comparison operators work seamlessly with BigInt and BigFloat types.

bramand — Arbitrary-Precision Big Numbers 
// Construct BigInt from string or number
let a = big_int("123456789012345678901234567890")
let b = big_int("987654321098765432109876543210")
let c = a + b
let pow2 = big_int("2") ** big_int("100")
println("Sum:", c.str())
println("2^100:", pow2.str())

// BigFloat with 128-bit default precision or custom precision
let bf = big_float("3.141592653589793238462643383279", 256)
let root = bf.sqrt()
println("Sqrt(PI):", root.str(20))
Linear Algebra

Vectors & Matrices (Linear Algebra)

High-performance vector and matrix primitives with built-in dot product, cross product, Euclidean norm, matrix multiplication, Gaussian elimination determinant (O(n³)), and Gauss-Jordan matrix inversion.

bramand — Vector and Matrix operations 
// Vector Operations
let v1 = vec([1.0, 2.0, 3.0])
let v2 = vec([4.0, 5.0, 6.0])
println("Dot product:", v1.dot(v2))
println("Cross product:", v1.cross(v2).elements)
println("Norm:", v1.norm())
println("Unit vector:", v1.normalize().elements)

// Matrix Operations
let m1 = matrix([[1.0, 2.0], [3.0, 4.0]])
let m2 = matrix([[2.0, 0.0], [1.0, 2.0]])
println("Matrix multiplication:", m1.mul(m2).data)
println("Determinant:", m1.det())
println("Inverse:", m1.inv().data)
Scientific Computing

Trigonometric, Logarithmic & Statistical Library

A rich suite of mathematical and descriptive statistical functions available out of the box with zero imports required.

bramand — Math and Statistics 
// Trigonometry & Exponentials
println("PI =", pi(), "E =", e())
println("sin(PI/2) =", sin(pi() / 2.0))
println("log10(1000) =", log10(1000.0))
println("hypot(3, 4) =", hypot(3.0, 4.0))

// Descriptive Statistics
let scores = [12.0, 15.0, 12.0, 18.0, 22.0, 25.0, 30.0]
println("Mean:", mean(scores))
println("Median:", median(scores))
println("Mode:", mode(scores))
println("Variance:", variance(scores))
println("Std Dev:", std_dev(scores))

Security

Cryptography & CSPRNG (Secure Random & UUIDv4)

Cryptographic hashing, HMAC authentication, cryptographically secure pseudo-random number generation (crypto/rand), and RFC 4122 v4 UUID creation.

bramand — Cryptography & Security 
// Cryptographic Hashing
println("SHA-256:", sha256("password"))
println("SHA-512:", sha512("password"))
println("MD5:    ", md5("data"))
println("HMAC:   ", hmac_sha256("secret-key", "message"))

// Cryptographically Secure Random & UUIDv4
let token = random_bytes(16)   // 32 hex chars
let dice = random_int(1, 6)      // [1, 6] range
let id = uuid()                  // RFC 4122 v4
println("Secure Token:", token)
println("UUID:", id)
