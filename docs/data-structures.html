Chapter 10

Arrays, Hashes & Index Expressions (arr[i] = v, hash[k] = v, obj.prop, .length)

BramandScript provides dynamic Arrays and Hash Tables (dictionaries) with rich index access, index mutation, and dot-property notation.

Arrays and Array Mutation

bramand — arrays 
let items = [10, 20, 30, 40]

// Index reading (0-based)
print("First:", items[0])      // 10

// In-place index mutation
items[1] = 999
print("Modified:", items)       // [10, 999, 30, 40]

// Property length access
print("Size:", items.length)    // 4

Hashes & Dot-Property Notation

Hashes support any hashable key (Integers, Strings, Booleans). String keys can be accessed and assigned using either bracket syntax hash["key"] or ergonomic dot syntax hash.key!

bramand — hashes 
let server = {
    "host": "127.0.0.1",
    "port": 8080,
    "active": true
}

// Dot property reading
print("Host:", server.host)

// Dot property assignment (inserts or updates key!)
server.port = 9000
server.environment = "production"

print("Updated server:", server)
print("Key count:", server.length)
Chapter 11

Iterators & for-in Loops (Arrays, Strings, Hashes, with break & continue)

BramandScript provides built-in for-in loops. The loop syntax optionally accepts an index variable before the item identifier.

bramand — for-in loops 
let languages = ["Go", "BramandScript", "Rust", "Zig"]

// 1. Item-only iteration
for lang in languages {
    print("Lang:", lang)
}

// 2. Index + Item iteration
for idx, lang in languages {
    print("[" + str(idx) + "]", lang)
}

// 3. Iterating over strings (character by character)
for char in "Bramand" {
    print("char:", char)
}

// 4. Early termination with break & continue
for i, val in [10, 20, 30, 40, 50] {
    if val == 20 { continue }
    if val == 40 { break }
    print("Yielded:", val)
}
Chapter 12

Structs & OOP Methods (struct Point { x, y, fn dist() { ... } })

BramandScript introduces clean object-oriented structs. A struct compiles into an instantiator closure that constructs a typed hash instance possessing the declared fields and bound methods.

bramand — structs and methods 
// Define a 2D Point struct with methods
struct Point {
    x, y

    fn distanceSquared(otherX, otherY) {
        let dx = x - otherX
        let dy = y - otherY
        return (dx ** 2) + (dy ** 2)
    }

    fn translate(offsetX, offsetY) {
        x += offsetX
        y += offsetY
    }
}

// Instantiation
let pt = Point(10, 20)

// Field access
print("Initial coordinates:", pt.x, pt.y)

// Method invocation
print("Dist to (0,0):", pt.distanceSquared(0, 0))

// Mutation via method or direct dot access
pt.translate(5, -10)
pt.x = 100
print("After translation:", pt.x, pt.y)
Chapter 13

Pattern Matching (match subject { case ... => { ... }, default => { ... } })

BramandScript features first-class pattern matching. Matching expressions return values, support multiple values per case separated by commas, and provide a fallback default arm.

bramand — pattern matching 
let statusCode = 404

let responseMessage = match statusCode {
    case 200, 201 => {
        "HTTP Request Succeeded"
    }
    case 400, 401, 403 => {
        "Client Permission or Format Error"
    }
    case 404 => {
        "Resource Not Found on Host"
    }
    default => {
        "Unknown Status or Server Fault"
    }
}

print("Result:", responseMessage)
