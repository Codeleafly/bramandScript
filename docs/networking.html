Networking, Web & AI Integrations

TCP & UDP sockets, HTTP web server and client, RFC 6455 WebSockets, streaming LLM integrations, and cosine vector similarity.

Sockets

TCP & UDP Client & Server Sockets

Low-level networking primitives built on pure Go stdlib (net). Supports both streaming TCP connections with line-by-line buffers and high-throughput UDP packet sockets.

bramand — TCP and UDP Socket Communication 
// Start TCP Listener
let srv = tcp_listen("127.0.0.1:8080")
spawn fn() {
    let conn = srv.accept()
    let line = conn.read_line()
    conn.write("echo:" + line + "\n")
    conn.close()
}()

// Connect TCP Client
let client = tcp_connect("127.0.0.1:8080")
client.write("Hello Network\n")
let response = client.read_line()
client.close()
srv.close()

// UDP Datagrams
let udpSrv = udp_listen("127.0.0.1:9090")
let udpCli = udp_connect("127.0.0.1:9090")
udpCli.write("fast_packet")
let pkt = udpSrv.recv_from()
println("Received:", pkt["data"], "from", pkt["addr"])
Web Framework

HTTP/HTTPS Client & Built-in Web Server

BramandScript provides two layers of HTTP routing:
1. Low-level Engine (http_server()): A lightweight built-in server for static endpoints, asset serving, and basic REST endpoints.
2. Advanced Radix Trie Router (std/net): A modular web framework with parameterized dynamic URL matching (:id), wildcard routes (*filepath), Route Groups (/api/v1), and middleware chains (cors, rate_limit).

bramand — HTTP Server & Client API 
// Instantiate Web Server
let app = http_server()

// Register Routes
app.get("/api/users", fn(req, res) {
    res.json([{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}])
})

app.post("/api/login", fn(req, res) {
    let body = req.json()
    res.status(201).json({"token": uuid(), "user": body["user"]})
})

// Host static directory and listen
app.static("/public", "./dist")
app.listen(3000, fn() {
    println("Server listening on http://127.0.0.1:3000")
})

// HTTP Client calls
let resp = http_get("http://127.0.0.1:3000/api/users")
println("Status:", resp.status, "Users:", resp.json())

// HTTP POST with JSON body and custom headers
let postResp = http_post("http://127.0.0.1:3000/api/users", {"name": "Charlie"}, {"Content-Type": "application/json"})
println("POST Status:", postResp.status)

// HTTP PUT and DELETE
let putResp = http_put("http://127.0.0.1:3000/api/users/2", {"name": "Robert"})
let delResp = http_delete("http://127.0.0.1:3000/api/users/1")

// Low-level http_request with timeout
let customResp = http_request({
    "method": "POST",
    "url": "http://127.0.0.1:3000/api/users",
    "body": {"name": "Eve"},
    "headers": {"X-App-ID": "bmd-client"},
    "timeout": 3000
})
println("Custom Request Status:", customResp.status)

Distributed Resiliency: Retries & Circuit Breakers

For production microservice resilience, network calls can be wrapped in std/retry with exponential backoff and guarded by std/circuitbreaker to prevent cascading failures during downstream outages:

bmd — Resilient HTTP with Retry & Circuit Breaker 
import "std/retry" as retry
import "std/circuitbreaker" as cb_mod

let breaker = cb_mod.new({
    "failure_threshold": 3,
    "reset_timeout": 5000,
    "fallback": fn() {
        return {"status": 200, "data": "cached-fallback"}
    }
})

// Call wrapped in circuit breaker and exponential backoff retry:
let outcome = breaker.execute(fn() {
    return retry.with_backoff(fn() {
        let resp = http_get("https://api.external/data", {"Accept": "application/json"})
        if resp.status >= 500 {
            throw f"Server error: {resp.status}"
        }
        return resp.json()
    }, 3, 50, 1000, 2)
})

println("Call succeeded:", outcome.ok)
println("Data payload:", outcome.result)
bramand — High-Level std/net Trie Router (:id and *path) 
import "std/net" as net

let router = net.new_router()

// Parameterized route: :id
router.get("/users/:id", fn(ctx) {
    let user_id = ctx.param("id")
    ctx.json(200, {"user_id": user_id})
})

// Wildcard route: *filepath
router.get("/static/*filepath", fn(ctx) {
    let file = ctx.param("filepath")
    ctx.text(200, "Serving: " + file)
})

// Route Groups & Middleware
let api = router.group("/api/v1")
api.use(net.cors("*"))
api.get("/metrics", fn(ctx) {
    ctx.json(200, {"uptime": 3600})
})
Realtime

RFC 6455 WebSockets (Zero-Dependency)

A complete, compliant implementation of the RFC 6455 WebSocket protocol built entirely with the Go Standard Library. Includes automatic client-side frame masking, server-side unmasking, ping/pong heartbeats, and binary/text frame streams.

bramand — Realtime WebSocket Communication 
// Start WebSocket Server
let wsSrv = ws_server("127.0.0.1:8081", "/ws")
spawn fn() {
    let conn = wsSrv.accept()
    while conn.is_open {
        let msg = conn.recv()
        if msg == null { break }
        conn.send("Server Ack: " + msg)
    }
}()

// Connect WebSocket Client
let ws = ws_connect("ws://127.0.0.1:8081/ws")
ws.send("Hello Bramand WebSocket!")
let reply = ws.recv()
println("Received:", reply)
ws.close()
wsSrv.close()
AI Integration

AI Integrations: LLM Streaming & Structured Outputs

First-class primitives for connecting to modern AI Large Language Models (Ollama, OpenAI, Gemini, Anthropic, and local vLLM/llama.cpp inference nodes). Features realtime token streaming using Server-Sent Events (SSE) and schema-validated structured JSON output generation.

bramand — LLM Streaming and Structured JSON 
// 1. Direct LLM Prompt (defaults to local Ollama http://localhost:11434)
let reply = ai_prompt("llama3", "Explain quantum computing in one sentence")
println(reply)

// 2. Realtime Token Streaming via Server-Sent Events
ai_stream({
    "url": "http://localhost:11434/api/generate",
    "body": {"model": "llama3", "prompt": "Write a haiku", "stream": true}
}, fn(token) {
    print_raw(token)  // Streams live tokens directly to console
})

// 3. Structured JSON Output Enforcement
let schema = {"sentiment": "positive|negative|neutral", "score": 0.0}
let parsed = ai_structured({
    "model": "llama3",
    "prompt": "Analyze: 'I love BramandScript!'"
}, schema)
println("Sentiment:", parsed["sentiment"], "Score:", parsed["score"])

Vector Similarity & AI Embeddings Search

High-dimensional vector distance metrics and nearest-neighbor search for AI retrieval-augmented generation (RAG) and embedding comparisons.

bramand — Vector Search and Distance Metrics 
// Distance & Similarity Metrics
let v1 = vec([1.0, 0.0, 0.5])
let v2 = vec([0.8, 0.2, 0.4])
println("Cosine Similarity:", cosine_similarity(v1, v2))
println("Cosine Distance:  ", cosine_distance(v1, v2))
println("Euclidean Distance:", euclidean_distance(v1, v2))

// Vector Database Search (RAG)
let query = vec([0.9, 0.1, 0.0])
let corpus = [
    {"id": "doc_1", "title": "Compiler Architecture", "embedding": vec([0.88, 0.12, 0.01])},
    {"id": "doc_2", "title": "Gardening Handbook",    "embedding": vec([0.05, 0.85, 0.52])},
    {"id": "doc_3", "title": "Bytecode Virtual Machine", "embedding": vec([0.92, 0.08, 0.02])}
]

let matches = vector_search(query, corpus, 2, "cosine")
println("Top Match:", matches[0]["item"]["title"], "Score:", matches[0]["score"])
