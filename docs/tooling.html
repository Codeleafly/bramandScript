Interactive REPL

Modern Terminal REPL Experience

BramandScript features a sleek, minimal, high-productivity terminal REPL built directly into the unified CLI (bramand repl or bmd repl). Designed with a clean international aesthetic adhering to our strict No-Emojis Policy, it presents crisp Unicode indicators (✦, ❯, ·), automatic block-depth continuation prompts, and built-in execution timing:

terminal — modern bmd repl session 
✦ BramandScript 0.1.1 (arm64-linux) · High-Performance Bytecode VM
  Type :help for documentation, :editor for multi-line, :exit to quit.

✦ bmd ❯ let greeting = "Hello, Universe!"
✦ bmd ❯ println(greeting)
Hello, Universe!

✦ bmd ❯ fn factorial(n) {
· ···     if n <= 1 { return 1 }
· ···     return n * factorial(n - 1)
· ···   }
✦ bmd ❯ factorial(7)

Multi-Line Buffer Editor Mode (:editor)

Type :editor or :edit [filename.bmd] to switch into multi-line buffered mode. Line numbers are automatically rendered, allowing you to edit multi-statement modules and functions before compiling. Type :done to execute or save directly to disk with :done <filename.bmd>:

terminal — :editor mode 
✦ bmd ❯ :editor math_util.bmd
__________________________________________________________________
Multi-Line Editor Mode
Type code line-by-line. Type :done to execute, :cancel to abort.
To save to file on disk: :done <filename.bmd>
__________________________________________________________________
01 | fn is_prime(n) {
02 |   if n <= 1 { return false }
03 |   let i = 2
04 |   while i * i <= n {
05 |     if n % i == 0 { return false }
06 |     i += 1
07 |   }
08 |   return true
09 | }
10 | println("Is 97 prime?", is_prime(97))
11 | :done
[OK] Saved 210 bytes to math_util.bmd
Executing buffer...
Is 97 prime? true

REPL Subcommands Reference

Command Description
:help Displays BramandScript language cheat sheet and syntax quick reference.
:editor / :edit [file] Enters multi-line buffered editor mode with line numbers and optional file destination.
:done [file] Compiles and executes editor buffer; optionally writes source code to disk.
:cancel Discards multi-line buffer and returns to standard REPL prompt.
:clear Clears terminal display and scrolls to top of viewport.
:reset Wipes VM symbol table, constant pool, and global variables store for a clean state.
:exit / :quit Gracefully closes REPL and exits to host terminal shell.
Diagnostics Engine

Zero-Box Clang/Rust-Style Diagnostic Engine

BramandScript employs a zero-box diagnostic formatter engineered for international terminal compatibility. Box-drawing characters (╭───╮, │, ╰───╯) commonly cause severe wrapping artifacts, broken vertical margins, and copy-paste corruptions on narrow mobile screens (Termux ARM64) and varied console emulators.

Our diagnostic engine replaces all box characters with clean, standard Clang/Rust-style vertical gutters (|), clickable file location links (--> file:line:col), 5-line contextual source windows, exact caret pointers (^), token span underlines (~~~), and actionable inline hints ([Hint: ...]):

terminal — zero-box compiler diagnostic 
✦ error[SyntaxError]: expected next token to be RPAREN, got INT instead
  --> server.bmd:14:28
   |
 9 |   let port = 8080
10 |   let host = "0.0.0.0"
11 |   
12 |   fn start_listener() {
13 |       println("Listening on", host, port)
14 |       if (connection_count > 100 200) {
   |                              ^~~ [Hint: check syntax for missing operator, parenthesis, or delimiter]
15 |           println("Server under load")
16 |       }
17 |   }
18 |   
19 |   start_listener()
   |

Diagnostic Architectural Principles

  • Clickable Hyperlinks (--> file:line:col): Formatted according to GNU/Rust convention, enabling direct click-to-open in VSCode, JetBrains, and modern terminal multiplexers.
  • 5-Line Source Window Context: Automatically loads up to 5 preceding and 5 succeeding lines surrounding the defect for instant situational context.
  • Exact Caret & Span Highlighting (^~~~): The caret points to the starting column, while tildes underline the token width.
  • Actionable Intelligence ([Hint: ...]): Every diagnostic is paired with heuristic rules that explain likely remedies directly in the terminal.
Tooling & Verification

CLI Test Runner & Native Testing Suite

BramandScript ships with a built-in zero-dependency testing framework and test runner. Run automated tests with microsecond reporting, sub-suite nesting, rich colored diagnostics, and micro-benchmarking:

bash — Test Runner CLI 
# Recursively discover and execute all *_test.bmd and test_*.bmd files
bramand test

# Run specific test file or directory
bramand test tests/
bramand test tests/01_language_foundation_test.bmd

Writing Test Suites (describe, test, assert_*)

bramand — math_test.bmd 
describe("Arithmetic & Vector Mathematics", fn() {
    test("Addition and scalar operations", fn() {
        let x = 15 + 25
        assert_eq(x, 40)
        assert_ne(x, 0)
        assert_true(x > 30)
        assert_false(x < 10)
    })

    test("Deep collection equality", fn() {
        assert_eq([1, 2, 3], [1, 2, 3])
        assert_eq({"status": "ok"}, {"status": "ok"})
        assert_not_null({"status": "ok"})
        assert_null(null)
    })
})
Code Formatter

Canonical Code Formatter (bramand fmt)

BramandScript includes a deterministic opinionated formatter built directly into the CLI toolchain (analogous to gofmt / cargo fmt). It normalizes indentation to 4 spaces, aligns operator spacing, cleans trailing whitespace, and verifies AST integrity:

bash — Formatter CLI 
# Format all .bmd files in current project in-place
bramand fmt

# Check if files adhere to canonical style (CI validation, exits 1 if unformatted)
bramand fmt -c
bramand fmt --check src/

# Format a specific file
bramand fmt examples/01_quickstart.bmd
Standalone Compilation

Standalone Executable Compilation (bramand build)

Compile any BramandScript program into a completely self-contained native executable. The generated binary contains the zero-dependency Bramand bytecode engine and embedded program payload, capable of running instantly on target systems without requiring Go or Bramand to be installed:

bash — Standalone Binary Builder 
# Build a standalone native binary for your platform
bramand build app.bmd -o my_app

# Explicit standalone packaging
bramand build app.bmd --standalone

# Run standalone executable directly (no interpreter or runtime needed!)
./my_app
Bytecode & Performance

Bytecode Disassembler & Execution Profiler

Inspect generated VM instructions and identify runtime bottlenecks using the built-in disassembler and profiler:

bash — CLI Disassembler & Profiler 
# Disassemble source file to bytecode instructions and constant pool
bramand disasm app.bmd

# Profile program execution with opcode timing and hotspot analysis
bramand profile app.bmd
Ecosystem Server

Centralized Package Registry Server (tools/registry_server.bmd)

BramandScript includes a full-featured centralized package registry server written in pure BramandScript (tools/registry_server.bmd). It provides publish APIs, tarball artifact storage, semver resolution, and search endpoints:

bash — Run Registry Server 
# Start package registry server on default port 8080
bramand run tools/registry_server.bmd

# Run test suite for package publishing, searching, and versioning
bramand test tests/15_day14_registry_test.bmd
